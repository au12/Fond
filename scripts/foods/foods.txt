# Fond's curated ingredient list. One food per line:
#
#   id | name | other names | category | options | field: value | field: value ...
#
# other names   comma separated. "garlic clove@clove" also tells Fond the unit.
# options       flour     counts as flour in baker's percentages
#               loose     unknown describing words are fine ("vidalia onion" is an onion)
#               any       a catch-all: even other foods' names are fine ("raspberry extract", "garlic herb seasoning")
#               est       always shown as an estimate (≈)
#               def=x     the state a bare cup means (def=chopped for onions)
#               nodefault only weigh when the line names a state ("shredded cheese")
#               skip      never weighed (bay leaves, cinnamon sticks)
#               noeach    ignore the counted portions in the source records
#               salt=x    which kind of salt this is (table, kosher, dc, morton, flaky)
# fields        sr:  the food's exact description in USDA SR Legacy
#               fn:  the same in USDA FNDDS, used where SR Legacy is silent
#               au:  the food's name in AUSNUT 2023
#               sr[cooked]: a second record whose plain measures describe a state
#               ref: a published kitchen value to cross-check against, "120/cup (King Arthur)"
#               pin: the value to use whatever the sources say; always give the reason
#               alt[dip]: the density under another convention (dip-and-sweep flour)
#               each: grams for counted items, "medium=110 large=150 clove=3"
#               water: water fraction, for hydration, when no SR record supplies it
#
# build.py takes the median across independent families (USDA, AUSNUT and any
# ref) and marks a food B when they disagree by more than 10 %. Run
# `python3 scripts/foods/build.py find <words>` to look up source records.
